# 图式抽取方法论

从日记中识别和提取认知图式的方法记录。

## 什么是图式

图式（Schema）是反复出现的认知模式——在特定情境下被触发、产生特定响应的心智结构。它不是一次性的想法或意图，而是一种可迁移的思维模板。

## 图式 vs 其他认知产出的区分

| 类型 | 特征 | 例子 |
|------|------|------|
| **图式** | 可迁移的认知模式，有触发-响应结构 | "讲故事传递意图" |
| **想法** | 一次性的洞察、假设、类比 | "门锁和空调一样适合做心智模型" |
| **意图** | 行动导向的目标或计划 | "在小说里写工作场景" |
| **情绪** | 情境中的情感状态 | "疲惫，valance=-1" |

关键判别：能否脱离原文语境独立存在并复用到其他场景。能 → 图式；不能 → 单次想法或意图。

## 抽取流程

1. **阅读日记**：通读当日记录，找出反复出现的思维模式
2. **归纳触发-响应**：什么情境触发了什么认知反应
3. **命名**：用精炼的中文短语概括图式核心
4. **去重**：同一图式不重复创建
5. **领域分类**：归入所属领域（叙事工程、认知工程等）
6. **描述核心思想**：用一句话说清图式"为什么重要"

## 格式

```yaml
title: 图式名称
description: 图式的核心思想——为什么它有价值，解决什么问题
```

## 当前图式清单

### 叙事工程

- **讲故事传递意图**：将产品意图封装进虚构故事，以半自传体设定作为载体，让用户在沉浸中自然理解设计背后的思考

### 认知工程

- **层次化心智模型**：认知模式具有天然的层次结构，每个层次单元应当足够小、足够精确，才能被有效识别和复用
