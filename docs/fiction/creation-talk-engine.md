# 创作谈引擎

从创作日志提炼创作谈。规则可变，提炼规则的程序不变。

## 用法

```
lab creation-talk <日志文件...>
```

输入：一个或多个创作日志（素材越具体越好——改前/改后对照最强，纯感想最弱）。

输出：一篇创作谈（Markdown），每条规则附日志原文作证据。

## 引擎的工作方式

SYSTEM_PROMPT 只写提炼方法，不写任何具体创作规则：

1. 通读素材，找出重复出现的做法（改了什么、怎么改的、为什么）
2. 把每个做法写成一条规则：一句话原则 + 日志原文作证据
3. **正反规则都收**：做得对的提炼为"要这样做"；反复踩的坑提炼为"别这样做"（如"不要替人物总结意义"）——负面教训与正面经验同等入谈，且负面规则往往更可执行
4. 没有重复出现的做法不写；素材不足就如实说"提炼不出规则"，或指出素材属于哪类（心境记录/完结告别等）不适合立规则
5. 产出以既有创作谈（fiction-revision.md）为格式样板

## 验收

1. 喂 fiction-revision.md 当年的素材，产出能对上现有七条中的五条以上
2. 喂一份没见过的日志，产出的每条规则都能指回日志原文
