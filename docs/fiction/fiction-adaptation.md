# 素材→正文的转化规律（改编方法论）

分析时间：2026-08-14。基于同章节脚本版（2_脚本）与成稿版（4_改稿）对比提炼（样本：6_2 海边散步、7_2 公园拥抱）。

## 核心认知

脚本写的是"作者想说的道理"，成稿写的是"角色演出来的情绪"——转化的本质是**从直述到演出**。

## 转化 8 条规律（操作级）

### 1. 场景先行

抽象素材 → 具体空间。脚本没场景，成稿必有场景——场景是情绪的容器。

- 例："海边孤独敲电脑" → 栈道 + 长椅 + 月光 + 潮声

### 2. 物证化

情绪必须有物证。直述"她关注我"读者不信；物证 + 悬念，读者信。

- 例："她一直关注他" → 长椅 + 邮箱窗口 + 全员信

### 3. 减法优先（删除率 70-80%）

脚本是情绪仓库，成稿是情绪提纯——删掉道理，留下感受。

- 例：7_2 脚本 35 行独白 → 成稿独白几乎全删
- 例：6_2 脚本"不确定/宿命"对话 → 成稿删光，只留一个核心情绪

### 4. 独白→问答（最核心的转化）

千言万语的自我陈述，压缩成一句互相撞击的问答——情绪浓度反而更高。

- 例："创始人的信心是灯塔"（35 行）→ "有人心疼过你吗？"——"有啊。我自己。"（2 行）

### 5. 动作外化

情绪 → 身体。成稿里情绪几乎不直说，全部通过身体动作发生。

- 压抑 → 呐喊；渴望 → 拽手腕跑；哭 → 衬衫湿了一小片；坚强 → 头埋得更深

### 6. 具象落点

结尾从道理 → 画面。每个章节用一个画面收束，不用总结句。

- 例："并肩而行" → "三十岁的他们，好像一对二十岁的年轻人"

### 7. 悬念保留

直述 → 对话悬念。

- 例："她很感动。没想到她一直关注自己" → "你大四那年是不是坐在那里捧着电脑写过东西？"——"你怎么知道..."

### 8. 素材分流

一个素材拆开用，素材不是被"用完"而是被"分配"到最合适的位置。

- 例：7_2 版本2 的父亲手术/家庭责任 → 挪到家庭线（12_3"回家看父母"方向）

## 应用清单（写 11_x 时）

```
1. 先给素材找场景（论坛/包子店/便利店）
2. 每个情绪找物证（演讲PPT/包子铺老板的女儿/老冰棍）
3. 删掉脚本里 70% 的对话，只留情绪内核
4. 把"她想说的道理"变成一问一答
5. 情绪全部外化成动作
6. 结尾用画面不用总结
```
