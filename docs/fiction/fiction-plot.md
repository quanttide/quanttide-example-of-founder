## 组织思路

### 1. 场景序列 = 关系距离的阶梯

陌生人 → 试探 → 破冰 → 进家 → 回溯 → 表白 → 公开 → 日常 → 家族/远方

每个场景推进一个距离刻度：重逢（物理接近）→ 深聊（心理接近）→ 进家（空间主权）→ 表白（关系确认）→ 聚餐（社会公开）→ 看星星（家族与终极）。没有过渡章节，全是"关系事件"。

### 2. 悬念管理：信息揭示的四层节奏

| 阶段 | 揭示内容 | 视角 |
| --- | --- | --- |
| 1_1/1_2 | 双方暗恋（日记/消息） | 读者已知，角色不知 |
| 2_1/4_2 | 旁观者确认双箭头（王助理吃瓜） | 第三者视角 |
| 6_2/7_1 | 十年守望的历史（身后/写信） | 互相揭示 |
| 8_2/10_1 | 牵线真相 + 19岁信（内心全景） | 补全+升华 |

"谁不知道什么"驱动张力——信息差是引擎，不是悬念情节。

### 3. 双线交织：浪漫线 × 治愈线

- 明线：重逢→在一起（外部进展）
- 暗线：男主的封闭/失眠/情绪索取 ↔ 女主的事业困境/十年守望——每章对话都在互相暴露创伤
- 7_2 是转折：她抱住他，他哭出来——治愈从单向守望变成双向

### 4. 物件装置：记忆的实体化（贯穿呼应）

```

毛巾擦水（1_1）→ 蒸汽眼罩（9_2）                    被照顾→照顾她
相册/日记（1_1）→ 19岁信（10_1）                     内心世界实体化
橙汁/白衬衫（5_1）→ 十年记忆对账                     记忆锚点
小火人（4_2）→ 关系契约的象征
```

- 王助理：旁观者确认（"双箭头"）+ 传递座位安排
- 餐馆老板们：生活质感 + 主题注脚

### 7. 元叙事：作者的思考直接入文

- 9_3/12_2：角色讨论 if 线（"二十岁在一起会怎样"）——校园言情=if 线的设计思想进入正文
- 12_3：三堵墙/自我整合/AI/千年远见——创作谈2 的哲学直接由男主说出
- 10_1：19岁写给29岁的信——"十年是回顾过去的十年"（创作谈）的文本化

### 8. 主题递进线

渴望被看见（1_1 相册）→ 互相看见（7_1 表白）→ 互相治愈（7_2 拥抱）→ 共同面对（9_3 事业/12_3 家族）→ 超越时间（12_3 千年星光）

爱情从自我救赎走向共同体——最后落在"回家看父母"，把私人爱情接入家族与时间的长河。

### 9. 场景选择逻辑：每个地点都有"十年对应物"

咖啡厅（今）↔ 教室（昔）；海边（昔守望）↔ 公园（今拥抱）；酒吧/夜市（今）↔ 校园（昔）——地点是时间坐标，空间移动 = 时间穿越。

## 一句话

作者用"关系事件"组织情节（无过渡、全高潮场景），用信息差管理悬念，用物件装置串联记忆，用双线（浪漫×治愈）让每个场景既推进关系又暴露创伤——最终从"渴望被看见"走向"互相治愈并共同面对世界"，把十年暗恋写成一部情绪驱动的治愈系叙事。
