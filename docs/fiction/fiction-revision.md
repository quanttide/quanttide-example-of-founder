# 前言精修原则（作者修订模式）

基于 2026-08-15《0_前言.md》两轮人工精修的 diff 归纳。两轮改动（用户 4 处 + 在 AI 精简基础上再改 7 处）呈现高度一致的稳定模式，可作为后续 AI 协助精修时的编辑准则。标注【两轮】为两次独立出现的确认模式。

## 1. 删除动机叙事：功利/商业考量不写进前言【两轮】

- 第一轮删"最初的动机很实际——想试试看，能不能多一个副业"及"当作副业来经营，实在困难"。
- 第二轮删"它们会成为公司的故事，成为品牌故事的一部分，因为这里也是我现实世界的延伸"。
- 原则：写作的私人意义不与商业/功利动机挂钩；保留的是"心力安全空间"这类内在动机。

## 2. 删除创作说明：不向读者解释"我为什么这样写"【两轮】

- 第一轮删"校园言情是职场言情的 if 线——如果他们二十岁就真的相遇了，会怎样"（设定推导）。
- 第二轮删"从现实来看，这种几乎不讲道理的等待并不存在，所以我用一个近乎科幻的设定来承载它"（设定动机）、"情绪不一定要和环境正相关，也可以相反"（方法论提炼）、"可迁移的情绪 / 设定影响了情节，而情节反过来启发我"整段机制解释。
- 原则：设定说明、写作机制、方法论总结一律删除，让事实/情节自己说话。删后需检查衔接词（"这份不讲道理""就像"）是否有指代断裂，必要时微调。

## 3. 弱化断言：确定式结论 → "我渐渐发现"【两轮，核心模式】

- 第一轮："我想写的其实是这句话" → "我渐渐发现，我想写的故事是"。
- 第二轮："这部小说不是一座可以装下一生的容器" → "我渐渐发现，这部小说不是……"。
- 原则：凡"其实/就是/答案是"式的确定断言，改用"我渐渐发现"开场；删"写作本身的答案——当你把故事讲得足够真诚"这类格言式总结。

## 4. 删除总结段：愿景/承诺段整体删除

- 第二轮删"我依然渴望写出更具爆发力的片段……"（抽象排比段）与"因此这本书会继续写下去……照亮你前行的路"（收尾承诺段）两整段。
- 原则：结尾前的"渴望/继续/答案"类总结段不保留，正文本身即结尾。

## 5. 结尾收敛：第一人称行动宣言，单落点【两轮】

- 第一轮结尾"这是一家公司把'敢说'写进自己底色的开始"最终删除（第二轮）。
- 第二轮结尾"这是一个人决定不再停留在原地" → "是我决定让自己不再停留在原地"。
- 原则：结尾不用旁观式判断（"这是一个人……"），用第一人称主动语态（"是我决定让自己……"）；个人/公司双落点收敛为单落点。

## 6. 合并紧凑：冒号引子删除，直接陈述

- 第二轮"写作教会我的最重要一件事是：\n\n把不敢说的，变成可以说的。"（两行+冒号）合并为一行"写作教会我的最重要一件事是：把不敢说的，变成可以说的。"。
- 原则：引导性冒号与换行不保留，引文直接并入陈述句。

## 7. 具体优先：抽象词堆叠删除，留画面

- 第二轮删"击中心底的某个地方 / 困扰已久的问题被消解 / 学会保持边界"，留"让那些想说出口的话终于可以说出口"。
- 原则：多个抽象排比只保留最具体的一个；删"写作的过程，比我想象中更诚实地改变了我"类概括句（前后文已体现，无需点明）。

## 应用方式

- AI 协助精修时按 1-7 逐条扫描；删除后检查衔接（指代、转折词）与段落呼吸。
- 作者保留判断权：以上为倾向性准则，不是硬规则（如公司维度内容作者曾一度保留，最终仍删）。

## 删除之后留下什么（本质）

两轮删除的共同指向，可以归纳为一个交换：

- **删掉的是作者对作品的解释**：动机（为什么写）、设定推导（为什么这样写）、写作机制（情绪怎么转化）、愿景承诺（还会继续写）——这些都在替读者总结意义。
- **留下的是作品与作者状态的证据**：事实与行为（做了什么）、具体意象（可感知的画面）、渐进领悟（渐渐发现）、一个行动宣言（当下这个决定）。

前言因此从"告诉你这是一部什么样的小说、我为什么写它"，变成"让你从事实里自己看出这些"。意义不再被作者说出，而是被读者提取。

这与情绪结构化处理器的哲学同构：**不做判断，只把材料摆出来**。精修原则本质上就是把这一原则应用到自己的文本上——不替读者总结意义，只把真实的东西放在那里。

最终检验：前言留下的那句"把不敢说的，变成可以说的"，不是这篇前言的总结，而是这篇前言本身做到的事。
