# p01 写作云 3R 引擎 — 实验方案

## 实验目的

验证"创作情境引导"作为核心交互模式的有效性——AI 不在已有文本之外生成内容，而是在已有文本中发现空隙并引导作者进入未写的场景。

## 背景

P0（Zed + AI 手动工作流）已验证一个完整 3R 循环可行。但每次启动需要手动配置提示词、分析完全依赖人工直觉。本 PoC 将方法论自动化，验证脱离聊天界面后核心算法是否成立。

日志 2026-06-02："写作云的原型找到了。目前Zed里，左侧是编辑器，右侧是创作灵感启发器。"

## 实验假设

1. 空隙检测（两个动作之间的半秒钟）可以通过文本模式匹配自动识别
2. 8 项创作方法论（三段式起草、逐句触感检查、层状删除等）可作为可执行的检查清单
3. 3R 循环的自动追踪比手动追踪更能帮助作者维持创作节奏

## 实验设计

### 核心工作流

```
输入：Markdown 草稿文件
  │
  ▼
┌─────────────────────┐
│ 1. Review 评审       │
│   ├─ 结构分析        │  段落比例、角色视角分布
│   ├─ 空隙检测        │  两个动作之间、时间跳跃、对话间隙
│   ├─ 风格检查        │  8 项方法论符合度评分
│   └─ 报告输出        │  评审摘要 + 改进建议
├─────────────────────┤
│ 2. Reflection 反思   │
│   ├─ 情境引导生成    │  基于空隙位置生成沉浸式引导语
│   ├─ 盲点提示        │  可能被跳过的时空/感受
│   └─ 风格方向对照    │  当前风格 vs 目标风格的差距
├─────────────────────┤
│ 3. Rewrite 改写      │
│   ├─ 版本差异记录    │  改写前后对比
│   ├─ 空隙填补追踪    │  原空隙是否被处理
│   └─ 循环统计        │  本轮修改量、周期时长
└─────────────────────┘
  │
  ▼
输出：3R 报告 + 下一轮入口提示
```

### 空隙检测规则

| 类型 | 匹配模式 | 示例 |
|------|---------|------|
| 动作间空隙 | 连续两个动作句之间缺少过渡 | "他推开门" → "他看到她" |
| 对话间隙 | 对话行之间没有动作/心理描写 | "嗯。" → "好。" |
| 时间跳跃 | 包含"第二天/之后/过了一会儿"等词 | "第二天清晨——" |
| 视角切换 | 段落视角转换时缺少重叠瞬间 | 从"他感觉"到"她想" |
| 收束检测 | 场景结尾是否停在紧张位置 | 状态句 vs 情节句判断 |

### 风格检查清单（8 项）

1. 对话→动作转化率
2. 身份标签→身体感知转化率
3. 对称叙事→交错叙事
4. 命名情绪→隐藏情绪
5. 过去闪回→碎片插入
6. 有限第三人称紧贴（视角锁定）
7. 状态句结尾 vs 情节句结尾
8. 半秒钟发现密度

## 评价标准

| 指标 | 合格线 | 优秀线 |
|------|--------|--------|
| 空隙检测准确率 | 50% 人工确认有效 | 80% 人工确认有效 |
| 情境引导可用率 | 30% 引导导致实际改写 | 60% 引导导致实际改写 |
| 单次分析耗时 | < 3s | < 1s |
| 方法论覆盖 | 5/8 项 | 8/8 项 |

## 原型实现

Python CLI 工具，包含：

- `review <file>` — 评审分析
- `reflect <file>` — 生成情境引导
- `rewrite <file> <newfile>` — 对比记录改写
- `session <file>` — 完整 3R 会话向导
