# 认知负担检测器（简易版）

## 核心目标

一眼看出 AI 写的文章哪里"难读"。

## 工作流程

输入 Markdown -> 6 项指标打分 -> 输出总分与修改建议。

---

## 1. 只看这 6 个指标

| 指标 | 看什么 | 权重 |
|------|--------|------|
| 逻辑跳跃 | 上下段不连贯？ | 0.25 |
| 无效表格 | 数据很少却强行列表？ | 0.15 |
| 废话连篇 | 车轱辘话反复说？ | 0.15 |
| 套娃标题 | 标题层级超过 3 层？ | 0.10 |
| 硬转折 | 段首没有过渡词？ | 0.20 |
| 概念轰炸 | 一段里新词太多？ | 0.15 |

## 2. 怎么算分？

每项 0-1 分。总分 = 各项分数加权求和。

- **< 0.30**：好文，直接用。
- **0.30 - 0.55**：偏高，挑高分项改。
- **> 0.55**：重写，别修了。

## 3. 怎么实现？

主要靠规则：数标题层级、算文本相似度、查过渡词表。快且免费。

实在不懂再问 AI：比如判断"这段话逻辑到底断没断"，才调用 LLM。

## 4. 怎么改？

根据报错直接改：

> **报错：第 12 段逻辑跳跃** -> 行动：加一句过渡句。

> **报错：表格无效** -> 行动：把表格变成一句话。

> **报错：概念轰炸** -> 行动：拆分成两段，或加个例子。
