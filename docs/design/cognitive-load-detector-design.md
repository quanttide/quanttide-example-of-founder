# 认知负担检测器（简易版）

## 核心目标

一眼看出 AI 写的文章哪里"难读"。

## 工作流程

输入 Markdown -> 6 项指标打分 -> 输出总分与修改建议。

---

## 1. 只看这 6 个指标

| 指标 | 看什么 | 权重 |
|------|--------|------|
| 逻辑跳跃 | 上下段不连贯？ | 0.25 |
| 无效表格 | 数据很少却强行列表？ | 0.15 |
| 废话连篇 | 车轱辘话反复说？ | 0.15 |
| 套娃标题 | 标题层级超过 3 层？ | 0.10 |
| 硬转折 | 段首没有过渡词？ | 0.20 |
| 概念轰炸 | 一段里新词太多？ | 0.15 |

## 2. 怎么算分？

每项 0-1 分。总分 = 各项分数加权求和。

- **< 0.30**：好文，直接用。
- **0.30 - 0.55**：偏高，挑高分项改。
- **> 0.55**：重写，别修了。

## 3. 怎么实现？

主要靠规则：数标题层级、算文本相似度、查过渡词表。快且免费。

实在不懂再问 AI：比如判断"这段话逻辑到底断没断"，才调用 LLM。

## 4. 怎么改？

根据报错直接改：

> **报错：第 12 段逻辑跳跃** -> 行动：加一句过渡句。

> **报错：表格无效** -> 行动：把表格变成一句话。

> **报错：概念轰炸** -> 行动：拆分成两段，或加个例子。

---

## 实现计划

- [x] 阶段 1：规则引擎 — 标题层级检测、过渡词表匹配、文本相似度
- [x] 阶段 2：LLM 辅助 — 仅在规则无法判断时调用
- [x] 阶段 3：报告输出 — 带行号的修改建议

## 实测结果（quanttide-data 文档集）

| 文档 | 评分 | 问题 |
|------|------|------|
| README.md | 100% (低) | 无 |
| why.md | 66% (中) | 概念密度 0%, 过渡词 0% |
| blueprint.md | 67% (中) | 概念密度 0%, 过渡词 6% |
| design-philosophy.md | 73% (中) | 过渡词 0%, 概念密度 40% |
| engineering-standards.md | 68% (中) | 过渡词 0%, 概念密度 10% |

**发现：** 所有文档的共同痛点是**概念密度过高**（每段引入 5-14 个新术语）和**缺乏过渡词**。标题层级和表格使用正常。这与文档的"思考笔记"性质一致——作者在梳理新概念体系时自然密集抛出新术语，但缺少对读者的引导。建议在关键概念密集段加过渡句和例子。

## 扩展：AI 输出常见毛病清单

当前检测器聚焦**表达层**。以下按场景整理了 AI 输出的其他常见问题，可供后续扩展检测维度。

### 结构层

| 毛病 | 表现 | 检测方式 |
|------|------|----------|
| 啰嗦循环 | 一个意思换三种说法反复说 | 文本相似度增强（跨段重复度） |
| 假过渡 | "此外""另一方面"后面跟的内容无逻辑关系 | LLM 语义判断 |
| 头重脚轻 | 开头长篇铺垫，核心内容草草收尾 | 段落长度分布分析 |
| 列表上瘾 | 几句话能说清却拆成 7 条 bullet | 列表占比检测 |
| 开头公式化 | "随着...的发展""近年来..."等空泛开头 | 金句词表匹配 |
| 没结尾 | 文章突然结束，没有收束总结 | 末段类型检测 |

### 内容层

| 毛病 | 表现 | 检测方式 |
|------|------|----------|
| 正确的废话 | "在当今数字化浪潮中"——信息量为零 | 废词/废句词表 |
| 幻觉数字 | "提升约 37.2% 的效率"（随口编的） | 来源引用检测 |
| 空洞承诺 | "通过本方案，您将获得前所未有的..." | 空泛句式匹配 |
| 缺例子 | 全程抽象概念，不给具体场景 | 例句子识别（"比如""例如"后无实质内容） |
| 堆砌术语 | 不用大白话，非要"赋能""闭环""颗粒度" | 黑话词表 |
| 假精确 | "大约""基本上""一定程度"高频堆叠 | 模糊词统计 |

### 场景特定

| 场景 | 常见毛病 |
|------|----------|
| 技术文档/教程 | 过度解释显而易见的，跳过真正复杂的前置知识；注释 `i += 1  // 将 i 增加 1` |
| 会议纪要 | 把没结论的讨论写成有结论；重要待办埋在大段文字里 |
| 邮件/沟通 | 十句话铺垫才能进入正题；过度礼貌 |
| 数据分析报告 | 把相关性当因果论证；对着明显图表写长篇解读 |
| 产品/营销文案 | 词汇泛滥化（"革命性""颠覆性"） |
| 翻译文本 | 硬译、欧化句式、术语不一致 |
| 问答/客服 | 反复道歉，不回答问题，模板化回复 |

### 优先建议

1. **正确的废话 + 空泛开头**：词表规则，零成本，最常见
2. **假过渡**：LLM 一次调用判断全文过渡词是否名副其实
3. **缺例子**：规则（扫描"例如""比如"后跟的内容长度）+ LLM 兜底
4. **黑话检测**：词表规则，适合团队自定义
