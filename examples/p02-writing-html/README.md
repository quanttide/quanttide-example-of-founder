# p02 写作云 HTML 原型

## 目标

在 Flutter 投入之前，用单 HTML 文件验证**三栏布局 + 3R 循环**的桌面交互体验。p01 验证了方法论算法，p02 验证界面布局和工作流。

## 验收标准

| # | 功能 | 验收条件 |
|---|------|---------|
| 1 | 三栏布局 | 项目面板（200px）、编辑器（自适应 ≥500px）、情境面板（300px），可拖动调整 |
| 2 | Markdown 编辑 | 左侧编辑区支持 Markdown 输入，右侧实时预览渲染 |
| 3 | 评审面板 | 调用 p01 引擎（write_poc.py）分析当前文本，在情境面板展示空隙列表和风格评分 |
| 4 | 情境引导 | 基于空隙位置生成沉浸式引导语，显示在情境面板中 |
| 5 | 3R 仪表盘 | 显示当前阶段（Review/Reflection/Rewrite）、循环轮次、周期时长 |
| 6 | 状态栏 | 底部显示字数、空隙数、上次提交时间 |

## 技术方案

- **单个 HTML 文件**（零外部依赖）
- CSS Grid 实现三栏布局
- 编辑器：`<textarea>` 或 `contenteditable` + marked.js（可选 CDN 加载）
- 与 p01 引擎集成：通过 `fetch` 调用本地 Python 服务（`write_poc.py --serve`），或内嵌简化版 JS 分析
- 本地存储：`localStorage` 保存当前项目和 3R 状态
