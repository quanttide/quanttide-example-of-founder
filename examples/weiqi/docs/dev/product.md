# 产品视角 · 产品设计描述

> 核心问题：做的是不是用户要的？

---

## 1. 产品定位

用一句话说清楚这是什么产品、为谁解决什么问题。

- **产品名称与定位语**：QtGame-weiqi —— 围棋爱好者的全能对弈与学习平台
- **核心价值主张**：为围棋爱好者提供一站式对弈、分析、练习与认证服务，让用户在任何阶段都能高效提升棋力。
- **目标用户画像**：
  - **入门棋童（6-12岁）**：需要趣味化死活题练习，配合AI辅助理解基础定式。
  - **业余爱好者（18-40岁）**：渴望在线匹配同级对手，通过棋谱分析复盘进步，并参加段位认证获取官方认可。
  - **高段位玩家（业余5段以上）**：需要高精度AI对手、复杂棋局分析功能，以及严谨的段位审核机制。

## 2. 功能清单

列出产品的所有功能，按优先级或模块分组。

### 核心闭环功能（P0）

- **AI辅助对弈**
  - **功能名称**：AI对弈
  - **用户价值**：可在无网络对手时随时与不同级别的AI对战，获得即时落子建议与胜率变化。
  - **优先级**：P0

- **在线匹配**
  - **功能名称**：在线匹配
  - **用户价值**：通过积分/段位自动匹配实力相近的真人玩家，进行公平竞技。
  - **优先级**：P0

- **段位认证**
  - **功能名称**：段位认证
  - **用户价值**：通过线上考试与实物奖杯确认个人棋力等级，获得权威认证证书。
  - **优先级**：P0

- **棋谱分析**
  - **功能名称**：棋谱分析
  - **用户价值**：上传/复盘任意对局，AI自动指出失误点、推荐最优变化，生成分析报告。
  - **优先级**：P0

- **死活题练习**
  - **功能名称**：死活题练习
  - **用户价值**：按难度分级刷题，系统自动判定正误并给出详细解说。
  - **优先级**：P0

### 体验增强功能（P1）

- **AI落子建议（对弈时）**
  - **功能名称**：AI落子建议
  - **用户价值**：对弈中可请求AI提示落子位置，但不强制使用，学习与实战结合。
  - **优先级**：P1

- **对局回顾**
  - **功能名称**：对局回顾
  - **用户价值**：在线对弈完成后自动保存棋谱，可随时回放并标注关键手。
  - **优先级**：P1

- **等级分系统**
  - **功能名称**：等级分系统
  - **用户价值**：基于Elo算法动态计算玩家实力，保证匹配更精准。
  - **优先级**：P1

- **隐藏眼位练习**
  - **功能名称**：隐藏眼位练习
  - **用户价值**：模拟实战中看不见眼位时的判断练习，提升棋感。
  - **优先级**：P1

### 锦上添花功能（P2）

- **社交功能**
  - **功能名称**：好友系统/聊天/观战
  - **用户价值**：添加好友、私聊、围观高手对局，提升社区氛围。
  - **优先级**：P2

- **打谱教学（经典棋局）**
  - **功能名称**：经典棋局打谱
  - **用户价值**：内置古今名局，可逐手学习高手思路。
  - **优先级**：P2

- **自定义AI参数**
  - **功能名称**：自定义AI参数
  - **用户价值**：高级用户可调整AI的搜索深度、模仿人类失误率等，获得更拟人化体验。
  - **优先级**：P2

## 3. 用户流程

描述一个典型用户的完整操作路径。

### 主流程：新人首局在线匹配

1. **用户意图**：想和实力相近的真人下棋 → **操作**：启动QtGame-weiqi，注册/登录 → **系统响应**：展示主界面，顶部导航栏包含“对弈”、“练习”、“棋谱”、“认证”等入口。
2. **用户意图**：快速开始一局匹配 → **操作**：点击“在线匹配”按钮 → **系统响应**：弹出匹配设置窗口（棋份、时间设置如19路/13路、基本用时+读秒），默认推荐与段位相符的条件。
3. **用户意图**：设置匹配选项 → **操作**：选择“19路棋盘”、“基本用时20分钟+3次30秒读秒”，点击“开始匹配” → **系统响应**：进入匹配队列，显示等待动画和预计等待时间（约10-60秒）。
4. **用户意图**：等待对手 → **操作**：无操作（或可点击“取消匹配”） → **系统响应**：匹配成功后弹出提示，加载棋盘界面。双方ID、段位、黑白色号显示在顶部。
5. **用户意图**：开始对局 → **操作**：黑方落子（用户或对手），轮流下棋 → **系统响应**：实时更新棋盘，记录每手时间戳，界面下方显示当前手数和双方用时。
6. **用户意图**：遇到困难想获取AI提示 → **操作**：点击“AI落子建议”图标（非强制功能，可关闭） → **系统响应**：在棋盘上高亮推荐落子位置（最多3个），并显示该手后续胜率变化。
7. **用户意图**：对局结束 → **操作**：系统自动判定输赢（或手动点目/投子） → **系统响应**：显示结果页，包含棋谱下载、自动保存至“我的棋谱”按钮。
8. **用户意图**：复盘分析 → **操作**：点击“棋谱分析” → **系统响应**：打开棋谱界面，系统加载该局AI分析结果，用不同颜色标注坏棋、疑问手、最优选点。
9. **用户意图**：查看段位变动 → **操作**：返回首页点击“个人中心” → **系统响应**：显示Elo等级分变化、段位徽章、胜率统计。

### 分支与边界情况

- **首次使用**：用户未设置段位时，系统强制先进行10局AI定级赛，根据胜负结果分配初始段位。
- **匹配超时（>2分钟无合适对手）**：系统弹出提示“当前段位活跃用户较少，是否放宽匹配范围（±1段）？”，用户确认后扩大匹配池。
- **对局中断（网络断开）**：每步落子自动上传服务器，掉线后30秒内重连可继续对局；超过30秒且未落子判负；若掉线前已经在读秒中，掉线期间读秒继续计时。
- **空状态（棋谱库无数据）**：首页“我的棋谱”区域显示“还没有对局记录，快去下一盘吧！”并附带“立即对弈”快捷按钮。
- **段位认证考试前置条件**：用户需完成至少20局有效匹配（无中途弃权）方可报名考试。

## 4. 设计决策与取舍

列出重要的产品决策和背后的理由。

- **决策**：将AI辅助对弈与在线匹配放在同等优先级，而非仅侧重其一。
  - **理由**：围棋用户群体包含两类核心需求：练习提升（AI）和社交竞技（匹配）。任何单一功能都可能导致用户流失。
  - **舍弃了什么**：暂未开发面向职业棋手的专业AI研究工具（如深度数据统计、自定义规则变体）。因为MVP阶段应聚焦核心用户（业余爱好者），职业特性可通过未来扩展实现。
  - **后续考量**：当用户量突破10万且活跃职业用户占比超过5%时，可增加专业模式。

- **决策**：段位认证采用“线上考试+实物证书”模式，而非纯积分制自动晋级。
  - **理由**：中国围棋协会的公认段位需要可靠监考环境。纯线上游戏积分难以被官方认可。线上考试（摄像头监考+AI防作弊）结合邮寄证书，既能便捷获取认证，又保持权威性。
  - **舍弃了什么**：取消了纯积分自动晋级（如达到X分自动升段）。因为这种模式会被刷分行为破坏公平性，且无法保证棋理真正达标。
  - **后续考量**：当区块链技术成熟且社区信任机制建立后，可考虑推出“链上段位”作为补充。

- **决策**：死活题练习中只提供AI自动判定正误，不开放多级提示（如“冷热”“思路”）。
  - **理由**：死活题训练的目的是培养计算力与独立发现手段的能力。过多提示会削弱核心价值。保留单一正误判定，配合解题后的详细变化图（自动播放），用户可自行研究。
  - **舍弃了什么**：放弃了“提示系统”（显示分支图、警告点）。避免用户养成依赖提示的习惯。
  - **后续考量**：如果用户调研显示初级用户因为题太难而流失，可增加“提示次数限制”或“付费解锁提示”选项。

- **决策**：棋谱分析默认使用固定AI强度（20秒/步），不提供“快速AI”和“深度AI”的显式选择。
  - **理由**：简化交互，避免用户困惑。20秒/步的AI足以分析99%的业余对局。极少数高段位用户可在设置中隐藏切换“深度分析（需要排队）”。
  - **舍弃了什么**：放弃了即时深度分析，因为深度AI（3分钟/步）会占用大量服务器资源，且排队时间长，降低多数用户满意度。
  - **后续考量**：当用户量稳定且服务器资源充裕后，可提供付费峰值套餐启用深度分析。

## 5. 内容策略

- **文案风格与语调**：古风典雅，融入围棋术语典故，如“落子无悔”“请君入局”“棋逢对手”。整体保持精炼、尊重用户智识，避免幼稚化或过度游戏化表达。
  - 按钮文案示例：“开始对弈”“复盘今局”“死活磨砺”。
  - 错误提示：“提子出错，您手滑了？请重新操作。”

- **术语表**

| 中文术语 | 英文对照 | 定义 |
|---------|---------|------|
| 对弈 | Game | 两人轮流落子的完整一局 |
| 棋谱 | Kifu / Game Record | 每手落子顺序的记录文件（.sgf） |
| 死活题 | Tsumego | 特定范围内的杀棋或活棋问题 |
| 段位 | Dan / Kyu | 棋力等级，1k-9k（级），1d-9d（段） |
| 匹配 | Match | 系统根据积分分配对手的过程 |
| AI落子建议 | AI Move Suggestion | 当前局面下AI推荐的最优选点 |
| 复盘 | Replay / Analysis | 对棋局进行回顾与AI点评 |

- **空状态、错误态、边界文案处理**：

  - **空状态**：
    - “我的棋谱”为空：“棋局尚未开启，执子定乾坤。”
    - 死活题列表为空（未出题）：“题库暂缺，少侠稍候。”
  - **错误态**：
    - 网络连接失败：“云局中断，检查网络后重连。”
    - AI分析失败（服务端超时）：“天机一时未至，请稍后重试。”
  - **边界**：
    - 用户等级超出系统可匹配范围（如9d vs 18k）：“鹤立鸡群，无旗鼓相当之敌，建议选择AI对弈。”
    - 认证考试提交失败：“提交后未保存，请重新完成最后一步。”
