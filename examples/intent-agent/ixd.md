意图澄清工具 — 交互设计说明（IXD）

1. 整体布局

左右双栏，等宽等高，无其他视觉噪音。

```
┌──────────────────────────────┬──────────────────────────────┐
│         左栏：对话            │       右栏：情境看板          │
│                              │                              │
│  ┌────────────────────────┐ │  ┌────────────────────────┐  │
│  │                        │ │  │ 情境卡片列表             │  │
│  │     对话历史            │ │  │                        │  │
│  │                        │ │  │  ┌──────────────────┐  │  │
│  │  AI回复 + 卡片提案附标  │ │  │  │ 卡片1 (已确认)   │  │  │
│  │                        │ │  │  └──────────────────┘  │  │
│  │                        │ │  │  ┌──────────────────┐  │  │
│  │                        │ │  │  │ 卡片2 (AI提案⏳) │  │  │
│  │                        │ │  │  └──────────────────┘  │  │
│  │                        │ │  │  ┌──────────────────┐  │  │
│  │                        │ │  │  │ 卡片3 (已确认)   │  │  │
│  │                        │ │  │  └──────────────────┘  │  │
│  └────────────────────────┘ │  └────────────────────────┘  │
│  ┌────────────────────────┐ │                              │
│  │  输入框                 │ │  [ 导出 BRD ]               │
│  └────────────────────────┘ │                              │
└──────────────────────────────┴──────────────────────────────┘
```

—

2. 左栏：对话区

功能：人与AI进行自然语言交互，推进探索。

特殊元素：

· AI回复下方可附带 “卡片提案” 提示：
  · 形式：轻量卡片缩略 + 一行说明：“根据刚才的对话，建议更新情境卡片：…”
  · 人可直接点击缩略进入右栏对应卡片处理

输入框：支持文字，发送即触发一轮对话。

—

3. 右栏：情境看板

内容：仅包含 情境意识卡片（暂不含心智模型）。

每张卡片代表一个情境节点，类型包括：

· 探索方向
· 尝试与结论
· 当前状态
· 下一步候选

卡片状态：

· 已确认：纯白背景，文字可编辑（点击即改），左侧有确认标记（如细竖线）
· AI提案：浅底色 + “⏳待确认”角标，文字可编辑，右侧出现操作按钮

AI提案操作：

· ✅ 接受 → 卡片转为已确认状态
· ✏️ 修改后接受 → 编辑文字后点确认，转为已确认
· ❌ 驳回 → 卡片消失，该提议作废

手动创建：右栏顶部有“+ 卡片”按钮，点击生成空白已确认卡片，直接进入编辑态。

卡片排序：支持手动拖拽排序（上下拖动），排序即最终导出顺序。

—

4. AI生成提案机制

触发条件：每轮对话结束后，AI 自动分析对话内容，判断是否产生新的情境节点或需要更新现有卡片。

提案形式：

· 在对话回复中附上提案摘要
· 同时在右栏对应位置创建一张“AI提案”状态的新卡片（或对已有卡片的修改建议）
· 若是对已有卡片的修改，原卡片背景不变，旁边浮动一个“建议修改”气泡，点击可预览差异

提案内容：纯文本，不包含格式化，最多 280 个字符。

—

5. 人机协作闭环

1. 人在左栏输入探索方向或问题
2. AI 回复，可能附带卡片提案
3. 人浏览右栏，处理提案（接受/修改/驳回）
4. 已确认的卡片构成“当前情境上下文”
5. 下一次对话时，系统自动将全部已确认卡片作为系统提示注入
6. 人在探索中随时手动编辑卡片或新增卡片，始终保有最终控制权

—

6. 导出 BRD

右栏底部固定按钮“导出 BRD”。

点击后：

· 将当前所有已确认卡片按顺序拼接为 Markdown 文档
· 每张卡片成为一个段落，卡片内容为段落正文
· 自动附加标题“情境意识 BRD” + 导出时间戳
· 提供下载或复制到剪贴板

导出的文档同时满足：

· 作为给其他 AI 实例的上下文（可无缝对接新的对话）
· 作为给人阅读的探索轨迹报告

—

7. 界面设计原则

· 极简：没有任何装饰性元素，无状态灯、无通知徽标
· 直接操作：所有交互都在卡片上原地完成，不弹窗、不跳转
· AI 原生：AI 主动贡献内容，人做轻量裁决
· 单一真相源：右栏已确认卡片是人和 AI 的唯一对齐基准

—

此设计满足“情境卡片既是 BRD 也是上下文”的核心诉求，交互流程清晰，工程实现成本低。可据此进入原型开发。
