意图澄清工具 — 交互设计说明（IXD）

1. 核心概念

意图澄清工具通过情境意识卡片在人与AI之间建立持续的对齐基线。每张卡片记录探索过程中的一个情境节点（方向、尝试、结论、状态、下一步）。卡片既是AI理解人类意图的高质量上下文，也可直接导出为业务需求文档（BRD）。

设计理念：

· 对话与看板同源：卡片直接生长于对话流，不分裂为两个独立界面。
· AI主动提案，人轻量裁决：AI从对话中自动识别情境变化，生成卡片提案；人通过简单操作确认或修正。
· 单真相源：所有已确认卡片构成唯一对齐基准，注入AI系统提示，驱动后续行为。

—

2. 桌面端布局

双栏等分，无任何装饰元素。

```
┌──────────────────────────────────────────────────────────────┐
│ 左栏：对话                           右栏：情境看板            │
│ ┌────────────────────────────────┐ ┌────────────────────────┐ │
│ │ 对话历史                        │ │ 卡片列表（可拖拽排序）  │ │
│ │                                │ │                        │ │
│ │ AI回复可能内嵌卡片提案          │ │ ┌ 卡片1 (已确认) ────┐ │ │
│ │  ┌ 缩略卡片 + “接受/驳回” ──┐  │ │ │ …                 │ │ │
│ │  └──────────────────────────┘  │ │ └────────────────────┘ │ │
│ │                                │ │ ┌ 卡片2 (AI提案⏳) ─┐ │ │
│ │                                │ │ │ …                 │ │ │
│ │                                │ │ └────────────────────┘ │ │
│ └────────────────────────────────┘ │                        │ │
│ ┌────────────────────────────────┐ │ ┌ 卡片3 (已确认) ────┐ │ │
│ │ 输入框                          │ │ │ …                 │ │ │
│ └────────────────────────────────┘ │ └────────────────────┘ │ │
│                                    │                        │ │
│                                    │ [+ 手动添加卡片]       │ │
│                                    │ [导出 BRD]             │ │
└────────────────────────────────────┴────────────────────────┘
```

左栏：对话区

· 标准聊天界面，支持自然语言输入。
· AI回复下方可能附带内联卡片提案（当AI认为需要记录情境节点时）。提案包含卡片内容预览，可直接点击“接受”或“驳回”，处理后的卡片自动进入右栏列表。

右栏：情境看板

· 展示所有卡片（含已确认和提案中）。
· 卡片状态：
  · 已确认：纯白背景，左侧绿色竖线，文字点击即可编辑。
  · AI提案：浅黄背景，左侧橙色竖线，右侧有“✓ 接受”“✗ 驳回”按钮，文字同样可编辑（修改后接受）。
· 卡片排序：拖拽手柄调整顺序，顺序决定导出文档结构。
· 手动创建：顶部“+ 卡片”按钮，生成空白已确认卡片。
· 导出：右下角“导出 BRD”按钮，将已确认卡片按顺序拼接为 Markdown 文档，自动添加标题和时间戳，复制到剪贴板或下载。

跨栏协同

· AI在对话中生成提案时，右栏同步出现一张新卡片（提案状态）。
· 左右栏高度独立滚动，互不遮挡。

—

3. 移动端布局

受限于窄屏，采用对话内嵌看板模式，避免视图切换造成的认知中断。

整体结构：单列全屏对话流，卡片直接在对话中展开，顶部常驻“当前情境”入口。

```
┌────────────────────┐
│ 标题栏：对话 / 情境  │  (点击切换)
├────────────────────┤
│ 当前情境 (可折叠)   │  ← 已确认卡片浓缩列表
│ ┌ 卡片1 ──────────┐│
│ └────────────────┘ │
│ ┌ 卡片2 ──────────┐│
│ └────────────────┘ │
├────────────────────┤
│                    │
│  对话历史           │
│                    │
│  AI回复 …          │
│  ┌ 卡片提案 ──────┐ │  ← 内嵌可操作卡片
│  │ 文字内容…      │ │
│  │ [接受] [驳回]  │ │
│  └────────────────┘ │
│                    │
├────────────────────┤
│ 输入框  [+卡片] [导出] │
└────────────────────┘
```

交互细节：

1. 内嵌卡片提案
   · 当AI生成情境节点时，在对话气泡正下方直接展开一张可编辑卡片，带有“待确认”底色和操作按钮。
   · 用户可立即编辑卡片文字，然后点击“接受”（变为已确认卡片）或“驳回”（卡片消失）。接受后的卡片自动收入顶部“当前情境”区域。
2. 当前情境区域
   · 位于对话列表顶部，默认折叠为一行（显示“当前情境 (3张卡片) ▼”），点击展开可查看所有已确认卡片。
   · 展开后每张卡片可点击编辑，长按拖拽排序，左滑删除。
   · 此区域始终可访问，不随对话滚动消失，确保情境意识持续可见。
3. 快捷操作
   · 输入框左侧“+卡片”按钮：直接创建一张空白已确认卡片，并添加到“当前情境”中，同时插入一条系统消息到对话流。
   · 输入框右侧“导出”按钮：将全部已确认卡片拼接为BRD文本，以AI消息的形式发送到对话流中，用户可复制或分享。
4. 视图切换（可选）
   · 标题栏可切换“对话”与“情境”视图，后者为全屏卡片列表（与桌面端右栏类似），供需要集中管理卡片时使用。但主要操作路径仍为对话内嵌。

—

4. AI提案机制（桌面/移动通用）

· 触发条件：每一轮对话后，AI判断是否出现新的情境节点（新方向、结论、状态变更、下一步等）。
· 提案生成：AI在回复中嵌入一个结构化提示，同时在卡片区域（桌面右栏/移动当前情境）创建一张“提案”状态卡片。
· 修改建议：若AI认为需要更新已有卡片，会在原卡片旁显示“建议修改”气泡，点击后可查看差异并确认。
· 内容规范：纯文本，最长280字符，不含格式化。

—

5. 人机协作闭环

1. 人在对话中输入探索意图。
2. AI回复并可能附带卡片提案（内嵌或同步至看板）。
3. 人处理提案：接受、修改后接受、或驳回。
4. 所有已确认卡片自动作为系统提示注入下一次AI请求。
5. 人可随时手动新增、编辑、删除、排序卡片。
6. 导出BRD供交接、归档或喂给新AI实例。

—

6. 界面设计原则

· 极简：无状态灯、通知徽标、装饰图形。
· 直接操作：卡片原地编辑，不弹窗。
· AI原生：AI主动提供结构化认知提案，人做轻量裁决。
· 单真相源：已确认卡片为唯一对齐基准，贯穿对话、上下文与导出。
· 同屏同流：桌面端双栏同步，移动端卡片内嵌对话，绝不因视图切换而中断认知。
