# 量潮创始人实验室 — 概念验证清单

面向写作云（qtcloud-write）的逐项验证序列。

## 分组 & 依赖关系

```
P1 — 创作工具（方法论验证）
└── p01 写作云 3R 引擎        依赖：无（独立验证）

P2 — 创作工具（界面验证）
└── p02 写作云 HTML 原型      依赖：p01（复用 3R 方法论）
```

## PoC 清单

| # | PoC | 验证目标 | 验收标准 |
|---|-----|---------|---------|
| 1 | 写作云 3R 引擎 | 创作情境引导核心模式有效：在已有文本中发现空隙，引导作者进入未写场景 | 空隙检测可用、情境引导可操作、3R 循环可追踪 |
| 2 | 写作云 HTML 原型 | 在投入 Flutter 之前验证三栏布局 + 3R 循环的桌面交互体验 | 三栏布局、Markdown 编辑、评审面板、情境引导、3R 仪表盘、状态栏六项可运行 |

## 推荐实施顺序

| 优先级 | PoC | 预估工作量 | 状态 |
|--------|-----|-----------|------|
| 1 | p01 写作云 3R 引擎 | 小 | 已实现 |
| 2 | p02 写作云 HTML 原型 | 小 | 待实现 |

## 技术栈

| 层 | 推荐选择 |
|----|---------|
| 写作引擎 | Python 3 CLI（p01） |
| 界面原型 | 单 HTML 文件（p02） |
| 版本控制 | Git（内置） |
| 文档 | MyST Markdown |
