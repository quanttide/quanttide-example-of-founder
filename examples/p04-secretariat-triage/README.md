# p04 秘书处任务分诊 — 实验方案

## 实验目的

验证任务自动分类、优先级排序、三办分派的逻辑是否覆盖秘书处日常工作场景。

## 背景

日志 2026-05-31：秘书处新人无经验，秘书长组织能力不足。三办分工定义详见 `docs/poc/index.md`（COO办商务、CTO办验收成本、秘书处办执行过程）。

## 实验假设

1. 任务可根据类型/紧急度/重要性自动分派到对应办公室
2. Eisenhower 优先级矩阵适用于秘书处的任务管理
3. 分诊规则可有效降低秘书长的手动协调负担

## 实验设计

### 阶段 1：任务分类验证

准备 12 个模拟任务，覆盖以下组合：

|----|---------|------|--------|--------|---------|

### 阶段 2：分诊规则调优

- 测试分诊规则的准确率
- 调整类型/紧急度/重要性的权重
- 验证人工干预和修正流程

### 阶段 3：负载看板验证

- 各办当前任务量
- 平均处理时间
- 超时任务告警

## 评价标准

| 指标 | 合格线 | 优秀线 |
|------|--------|--------|
| 分类准确率 | 9/12 (75%) | 11/12 (92%) |
| 优先级排序合理性 | 错排率 ≤ 1 个 / 12 个 | 错排率 = 0 |
| 人工修正流程 | 可用 | 顺畅 |
| 看板实时性 | 秒级 | 实时 |

## 原型实现

分诊面板 + 各办看板，包含：

- 任务输入表单
- 自动分诊结果展示（含置信度）
- 人工修正按钮
- 各办看板（待办/处理中/已完成）
- 优先级矩阵可视化
