# p01 招聘筛选网关 — 实验方案

## 实验目的

验证用系统自动过滤低质量简历、引导高质量候选人的流程是否可行。

## 背景

日志 2026-05-28：招聘数量增多，低质量占比变大，需要用系统对抗系统。目标是"让愿意为我们花时间的人被筛选出来"。

## 实验假设

1. 简历信息完整度 + 关键词匹配度可以作为有效的初筛标准
2. 系统自动拒绝低质量投递后，候选人转化率会提升
3. 引导流程能区分"随意投递"和"有意向但信息不全"两种情形

## 实验设计

### 阶段 1：评分规则验证

准备 10 份模拟简历（首轮小样本验证，后续扩展至 50+），覆盖以下类型：

| 类型 | 描述 |
|------|------|
| A 类 | 信息完整、高度匹配 | 预期：高分通过 |
| B 类 | 信息完整、部分匹配 | 预期：中分，进入人工 |
| C 类 | 信息极少、无匹配 | 预期：自动拒绝 |
| D 类 | 信息中等、错配岗位 | 预期：标记后转推荐 |

### 阶段 2：引导流程验证

对 B/C/D 类设计不同的反馈文案，验证候选人是否按引导补充信息或转投其他岗位。

### 阶段 3：统计面板验证

验证过滤率、通过率、转化率三个指标的计算和展示。

## 评价标准

| 指标 | 合格线 | 优秀线 |
|------|--------|--------|
| A 类识别准确率 | 100% | 100% |
| C 类自动拒绝准确率 | 90% (首轮最低 3/3) | 100% |
| B 类引导后补充率 | 40% (假设基线，首轮验证后修正) | 60% |
| 全流程时间 | ≤ 3 轮交互 | ≤ 2 轮交互 |

> 上述百分比基于首轮 10 份样本，后续扩充后重新校准。

## 原型实现

可交互的招聘筛选面板，包含：

- 简历列表 + 评分展示
- 评分规则配置区
- 候选人详情 + 操作按钮
- 统计看板
