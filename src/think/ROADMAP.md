# think ROADMAP

> 认知提炼 — 从 memory 中自下而上抽取认知要素

## 实验 1.1：从 memory 中识别情境

输入：原始 memory 文本（日记、笔记、日志）
输出：结构化情境记录

- [ ] 步骤 1.1.1：收集 memory 样本，确定输入格式
- [ ] 步骤 1.1.2：定义情境数据结构（时间、地点、参与者、活动、情绪）
- [ ] 步骤 1.1.3：编写抽取脚本（关键词/规则匹配）
- [ ] 步骤 1.1.4：人工验证抽取结果，修正错误
- [ ] 步骤 1.1.5：对情境进行自然聚类，观察涌现类型

## 实验 1.2：提取意图与想法

输入：结构化情境记录
输出：意图记录 + 想法记录（含情境引用）

- [ ] 步骤 1.2.1：标注意图（目标、动机、计划、承诺）
- [ ] 步骤 1.2.2：标注想法（洞察、假设、问题、类比）
- [ ] 步骤 1.2.3：实现抽取脚本，关联到所属情境
- [ ] 步骤 1.2.4：验证覆盖度，统计共现关系

## 实验 1.3：从数据中归纳图式

输入：情境 + 意图 + 想法 数据集
输出：图式候选集

- [ ] 步骤 1.3.1：情境模式分析，提取重复结构为事件图式
- [ ] 步骤 1.3.2：高频意图提炼为动机图式
- [ ] 步骤 1.3.3：意图-想法共现组合提炼为决策图式
- [ ] 步骤 1.3.4：人工评估候选图式，合并相似、剔除噪音
- [ ] 步骤 1.3.5：交付图式候选集，记录归纳过程
