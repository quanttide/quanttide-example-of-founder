# data — 标注确认模块

用 TODO 式标记确认 think 模块的提取结果。

## 工作流

```bash
python3 src/data/extract.py          # 生成带标记的 ANNOTATION.md
# 编辑 ANNOTATION.md，修改标记
python3 src/data/extract.py --apply  # 读取标记变更，输出确认结果
```

## 标记体系

| 标记 | 含义 | 操作 |
|------|------|------|
| `[ ]` | 待确认 | 默认状态 |
| `[x]` | 已采纳 | 空格→x |
| `[-]` | 已废弃 | 空格→- |
| `[?]` | 待决策 | 空格→? |
| `[~]` | 已修改 | 改内容时标记 |

## 下游

- `[x]` → 进入 execute 的候选
- `[-]` → 记录废弃理由
- `[?]` → 进入待决策队列
